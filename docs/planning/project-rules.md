## 4. 반드시 지켜야 할 원칙 (하드 룰)

### 4-1. 근거·출처
- **모든 기준표는 출처가 명확해야 한다.** 자체 제작한 평가 기준표(연령·성별 컷오프 등)를 만들지 않는다. 공단이 실측정하지 않은 종목에 공단을 출처로 표기하지 않는다.
- 백분위·규준은 반드시 **실제 공단 데이터에서 산출**한다. 홈 측정용 더미/시뮬레이션 분포를 만들지 않는다.

### 4-2. 통계적 방법론
- 규준(`fitness_norm`)은 **다년도 전체를 풀링**해서 구축한다. 단일·소수 월 데이터로 규준을 만들지 않는다 (계절 편향 확인됨, STATUS.md 4-3 참고).
- 서브그룹(성별×연령대)별 표본이 최소 100건 이상인지 확인 후 규준에 사용한다.
- 백분위는 z-score가 아니라 **백분위(순위 기반)**로 산출한다 (체력 분포는 정규분포 가정이 안 맞는 경우가 많음).
- BMI·허리둘레·혈압은 U자형 분포/스크리닝 성격이므로 **백분위 대상에서 제외**하고 카테고리 판정(정상/주의 등)으로 처리한다.

### 4-3. 홈 측정 종목 선정
- 홈 자가측정 배터리는 **센터 정식 종목·동일 프로토콜만** 채택한다. 종목이나 단위를 임의로 바꾸지 않는다.
- 홈에서 재현 불가능한 종목(전용 장비 필요, 안전 위험 등)은 추정치로 채우지 않고 **"측정 불가 — 센터 방문 권장"**으로 명시한다.
- 미커버 요인(예: 근력·심폐지구력)으로 인한 처방 편향을 막기 위해, 처방 로직은 **"기본 구성(유산소+근력 항상 포함) + 약점 가중"** 구조로 설계한다.

### 4-4. 등급·인증 표시
- 국민체력100 인증등급은 **공식 기관(체력인증센터)만 발급 가능**하다 (문화체육관광부 고시). 자체 서비스가 정식 인증서를 발급하는 것처럼 보이면 안 된다.
- 등급은 1~6등급이다 (1~5등급 아님 — 4~6등급은 2025년부터 실제 운영).
- 등급 표시 여부는 아직 팀 미확정. 표시하기로 결정되더라도 반드시 "실제 인증 등급과 차이가 있음"을 명시하는 disclaimer를 붙인다 (공단 자가측정 페이지 선례 참고).

### 4-5. 안전
- 측정 전 **PAR-Q(공단 공식 7문항)를 게이트로 둔다.** 처방 단계가 아니라 **측정 이전 단계**에 배치한다 (홈 배터리에도 최대 노력 과제가 포함되므로).
- PAR-Q 1개 이상 '예' 응답 시: 자가측정 가이드·자동 처방은 차단하고 센터 안내로 전환한다. 단, 센터 측정값 입력 기반 리포트와 공단 영상 열람은 계속 허용한다.
- PAR-Q 개별 문항 응답은 **저장하지 않는다** (건강 관련 민감정보). 판정 결과(pass/fail)만 저장한다.
- 장애유형별 자동 처방은 만들지 않되, 안전 fallback(PAR-Q 라우팅)이 이 케이스를 흡수하도록 한다. "아무 분기 없음"은 일반 처방을 그대로 내보내는 최악의 상태이므로 반드시 라우팅 로직을 넣는다.

### 4-6. DB 설계
- 센터/홈 트랙을 **물리적으로 분리한 테이블로 만들지 않는다.** 단일 `measurement` 테이블 + `source` 컬럼(CENTER/HOME) 구조를 쓴다.
- 추천/처방 쿼리도 트랙별로 나누지 않고 **단일 쿼리**로 유지한다 (요인 기반 매칭이라 트랙 구분이 필요 없음).
- 홈-센터 측정 조건 차이는 **산출 로직이 아니라 표기 단계**에서 처리한다 (예: 점추정 대신 구간 표시).

### 4-7. 데이터 클리닝
- 원본 CSV 중 다음 파일은 분석·적재 시 항상 제외한다:
  - `KS_..._020206.csv` — 2025년 6월 데이터 중복본
  - `KS_..._202603.csv` — 2026년 3월 데이터 중 하루치만 있는 부분월
- 새로운 원본 데이터를 받을 때마다 파일명·날짜 필드 정합성을 먼저 확인한다.

## 5. 절대 하면 안 되는 것

- ❌ 출처 불명확한 평가 기준표를 만들거나 그대로 채택하기
- ❌ 홈 측정용 백분위를 위해 별도의 "홈 전용 시뮬레이션 분포" 만들기
- ❌ 등급을 공식 인증서처럼 disclaimer 없이 표시하기
- ❌ 국민체력100을 "1~5등급 체계"로 잘못 표기하기
- ❌ 측정 안 된 요인(악력·심폐 등)을 추정치로 채워 넣기
- ❌ 장애·질환 관련 안전 문진 없이 자동 처방 내보내기
- ❌ PAR-Q 개별 문항 응답을 DB에 저장하기
- ❌ 센터/홈 트랙별로 쿼리나 테이블을 두 벌 만들기
- ❌ 단일 월(또는 소수 월) 데이터로 규준(백분위 기준) 만들기
- ❌ 중복 파일(`020206.csv`)·부분월 파일(`202603.csv`) 그대로 집계에 포함하기
