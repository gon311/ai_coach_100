SCR-01

메인 대시보드

진입 · 등급 확인 · 측정 시작

앱을 열었을 때 첫 화면입니다. 최근 등급을 한눈에 보여주고 새 측정으로 유도하는 두 가지 일만 합니다.

1 2 3
  1. 1

    나의 홈 체력 종합 등급

    가장 최근 측정 결과를 1~6등급으로 표시합니다.

    데이터
    최근 측정 1건의 종합 등급, 측정일
    빈 상태
    기록이 없으면 등급 자리에 “측정 전” 뱃지, 측정일 줄은 숨김
  2. 2

    빈 상태 일러스트 영역

    기록이 있을 때는 이 자리를 최근 4종목 요약이나 재측정 권유로 바꾸는 편이 낫습니다. 현재는 등급이 있어도 “진단해보세요”가 떠서 화면 위아래 메시지가 어긋납니다.

  3. 3

    새로운 체력 측정하기

    인터랙션
    탭 → 배경 딤 처리 + 하단에서 바텀시트 슬라이드 업
    선택지
    센터 기록 연동 → 국민체력100 인증·조회 / 집에서 셀프 측정 → SCR-02a
  4. ·

    바텀시트

    스펙에는 정의되어 있으나 화면이 아직 없습니다. 딤 위에 올라오는 2지선다 시트 1장이 필요합니다.

SCR-02a

건강 문진표 (PAR-Q)

Step 1 · 안전 게이트

집에서 혼자 운동하게 되므로, 측정 전에 위험 요인을 거르는 필수 관문입니다. 서비스가 의학적 판단을 하지 않는다는 방어선이기도 합니다.

1 2 3
  1. 1

    스텝 표시와 제목

    2단계 입력 중 첫 번째임을 알립니다. 뒤로가기는 SCR-01로 복귀하며, 입력값은 버립니다.

  2. 2

    필수 문항 4개

    항목
    관절 통증 · 운동 중 흉통 · 어지럼증으로 인한 실신 · 고혈압/심장약 복용
    기본값
    전부 미체크. 건너뛰기 없음
  3. 3

    해당사항 없음 (다음으로)

    활성 조건
    체크 0개일 때만 활성
    체크 시
    “의사와의 상담이 필요합니다” 얼럿 → 측정 플로우 차단, 센터 안내로 라우팅
  4. ·

    차단 화면

    체크가 하나라도 있을 때 보게 될 얼럿·안내 화면이 없습니다. 이 서비스에서 가장 민감한 분기라 화면으로 명시해두는 편이 안전합니다.

결정이 필요한 것

  • 정책
    버튼 라벨 — 체크가 생기면 “해당사항 없음”이라는 문구가 사실과 어긋납니다. 체크 시 “상담 안내 보기”로 라벨을 바꿀지, 버튼을 비활성으로 둘지 정해야 합니다.
  • 정책
    차단 강도 — 완전 차단할지, “책임은 본인에게” 동의 후 진행을 허용할지. 공모전 심사에서는 완전 차단 + 센터 방문 권유가 방어하기 쉽습니다.
SCR-02b

신체 정보 입력

Step 2 · 기준값 산출

등급 판정의 기준을 정하는 값을 받습니다. 여기서 받은 값이 SCR-05의 또래 비교 축을 결정합니다.

1 2 3
  1. 1

    출생년도

    용도
    연령대 산출 → 또래 비교 기준 구간 결정
    입력
    숫자 키패드, 4자리. 범위 밖 값은 인라인 오류
  2. 2

    키 · 몸무게

    용도
    BMI 산출 → SCR-05 레이더의 체성분 축
    입력
    숫자 키패드. 소수점 허용 여부 확정 필요
  3. 3

    입력 완료

    3개 항목이 모두 유효할 때 활성화되고, 누르면 SCR-03으로 이동합니다.

결정이 필요한 것

  • 누락
    성별 입력이 없습니다. 국민체력100 기준표와 우리가 쓰려는 측정결과 데이터는 모두 성별·연령대 교차로 분포가 나뉩니다. 성별 없이는 SCR-05의 등급도 또래 평균 점선도 산출할 수 없습니다. 이 화면에 필드 하나가 추가되어야 합니다.
  • 정책
    값 저장 범위 — 매 측정마다 다시 입력받을지, 프로필에 저장해두고 재측정 때 건너뛸지. 저장한다면 SCR-01에 프로필 수정 진입점이 필요합니다.
SCR-03

측정 브리핑

사전 안내 · 이탈 방지

무엇을 몇 분 동안 하게 되는지 먼저 알려줍니다. 준비 없이 시작해서 중간에 그만두는 것을 막는 화면입니다.

1 2 3
  1. 1

    예상 소요시간

    약 10분. 4종목 수행 시간에 종목 간 휴식을 더한 값으로, 실제 타이머 합계와 어긋나지 않게 확정해야 합니다.

  2. 2

    4종목 타임라인

    순서
    유연성(앉아 윗몸 굽히기) → 근지구력(플랭크) → 하체근력(월 시트) → 심폐지구력(3분 스텝)
    종목 선정
    공동주택 소음을 고려해 제자리 멀리뛰기 등 충격·점프 종목을 제외하고 정적 버티기 위주로 대체
  3. 3

    측정 시작하기

    첫 종목(유연성)의 SCR-04로 이동합니다.

  4. ·

    준비물 안내

    월 시트는 벽, 앉아 윗몸 굽히기는 줄자나 자가 필요합니다. 이 화면에 한 줄 넣지 않으면 SCR-04에서 이탈이 생깁니다.

SCR-04

종목별 테스트

핵심 인터랙션 · 4회 반복

실제로 몸을 움직이며 기록을 남기는 화면입니다. 종목만 바뀌며 네 번 반복됩니다. 화면에서 1~2m 떨어진 상태로 보게 되므로 타이머가 화면의 주인공입니다.

1 2 3 4
  1. 1

    진행 인디케이터

    점 4개로 현재 몇 번째 종목인지 표시합니다. 좌측 닫기(×)는 측정 전체를 중단하므로 확인 얼럿이 필요합니다.

  2. 2

    자세 가이드 영상

    미디어
    짧은 루핑 영상 또는 GIF. 무음 자동재생
    출처
    국민체력100 운동처방 동영상 API를 쓰면 공공데이터 활용 실적으로 잡힙니다
  3. 3

    빅 타이머

    초 단위 카운트 업. 아래 보조문구는 종목마다 종료 조건을 다르게 안내합니다(예: 바른 자세가 무너질 때까지).

  4. 4

    컨트롤 버튼

    상태
    측정 시작 → 일시정지 → 기록 완료
    기록 완료
    측정값을 입력 폼에 세팅. 사용자가 수동 수정 가능 → 다음 종목으로

결정이 필요한 것

  • 누락
    시간형이 아닌 종목의 화면 — 앉아 윗몸 굽히기는 cm, 3분 스텝 테스트는 종료 후 회복 심박수를 받습니다. 타이머 자리에 숫자 입력이 들어가는 변형 화면 1~2종이 더 필요합니다.
  • 디자인
    이 화면만 다크 테마입니다. 측정 몰입과 눈부심 감소가 목적이면 의도된 선택이니 보고서에 근거를 적어두고, 아니라면 나머지와 통일하는 편이 좋습니다.
  • 정책
    중단 후 복귀 — 3번째 종목에서 앱을 껐다 켜면 이어서 할 수 있는지. MVP에서는 처음부터 다시로 두고 안내 문구만 넣는 것도 방법입니다.
SCR-05

결과 리포트

종합 등급 · 또래 비교 · 운동 추천

측정의 보상이자 서비스의 차별점이 모이는 화면입니다. 등급 → 약점 진단 → 보완 콘텐츠까지 한 화면에서 이어집니다.

1 2 3
  1. 1

    종합 등급

    산출
    4종목 + BMI를 합산해 1~6등급으로 분류
    확정 필요
    5개 축의 가중치와 등급 경계값. 근거를 밝힐 수 있어야 합니다
  2. 2

    체력 밸런스 레이더

    축
    유연성 · 근지구력 · 하체근력 · 심폐지구력 · 체성분
    비교
    파란 면은 나, 점선은 동일 성별·연령대 평균. 현재 스크린샷에는 점선 오버레이가 빠져 있습니다
  3. 3

    AI 맞춤 솔루션 카드

    규칙
    레이더에서 가장 낮은 축을 문장으로 짚어주고, 그 요인을 보완하는 10분 홈트레이닝 영상 카드를 추천
    상태
    현재 화면에는 이 영역이 비어 있습니다

결정이 필요한 것

  • 누락
    솔루션 카드 영역이 그려져 있지 않습니다. 결과 화면의 아래 절반이자 심사에서 가장 눈에 띄는 부분이므로 우선 채워야 합니다.
  • 데이터
    추천 영상 출처 — 스펙에는 유튜브로 적혀 있지만, 공모전 요건상 국민체력100 운동처방 동영상 데이터를 쓰는 편이 유리합니다. 체력요인 → 운동 → 영상으로 이어지는 매핑 테이블을 서비스 내부에 두는 구조입니다.
  • 데이터
    또래 평균 점선의 표본 — 성별·연령대 구간별로 표본이 충분한 구간과 부족한 구간이 갈립니다. 부족한 구간은 점선을 흐리게 하거나 “표본 부족” 라벨을 붙이는 처리가 필요합니다.

다음에 그려야 할 화면

  • SCR-01-M 측정 방식 선택 바텀시트 — 플로우가 여기서 갈라지므로 최우선
  • SCR-02a-E 문진표 체크 시 차단·상담 안내 — 안전 방어선
  • SCR-04-N 숫자 입력형 측정 화면 (cm, 회, 심박수) — 4종목 중 2종목이 여기에 해당
  • SCR-05-B 결과 화면 하단의 솔루션 카드 — 심사 핵심 화면
  • SCR-01-E 측정 기록이 없는 첫 진입 상태 — 신규 사용자가 처음 보는 화면
측정 결과는 운동 참고 정보이며 의학적 진단이 아닙니다. 통증·질환 관련 문의는 전문가 상담으로 안내합니다.
