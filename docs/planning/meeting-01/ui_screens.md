# 홈 체력 측정 UI 화면 설계서

각 단계별 핵심 화면(Screen)의 목적과 UI 구성 요소를 구체화한 설계안입니다.

## Screen 1. 메인 홈 및 측정 방식 선택
사용자가 앱에 진입하여 가장 먼저 마주하는 화면입니다.
- **상단부:** 사용자 프로필 및 현재 홈 체력 등급 요약 (최근 측정일 표기)
- **메인 액션 버튼:** 큼직한 `[+ 새로운 체력 측정하기]` 버튼
- **바텀 시트(Bottom Sheet) 등장:** 버튼 클릭 시 화면 아래에서 선택창이 올라옴
  - 옵션 A: 🏢 **국민체력100 센터 기록 불러오기** (카카오 인증 등을 통해 연동)
  - 옵션 B: 🏠 **집에서 셀프 체력 측정하기** (소음 방지 모드)

## Screen 2. 사전 건강 체크 및 신체 정보 (Pre-test & Profile)
안전사고를 예방하고 정확한 결과를 내기 위한 준비 단계입니다.
- **Step 1. 건강 문진표 (PAR-Q):** 
  - "현재 관절에 통증이 있나요?", "어지러움을 느낀 적이 있나요?" 등의 3~4가지 핵심 질문
  - 모든 항목에 `[아니오]` 선택 시 다음 단계 버튼 활성화
- **Step 2. 신체 정보 입력:**
  - 성별, 생년월일 (나이 계산용)
  - 키(cm), 몸무게(kg) 스크롤 휠 또는 키패드 입력 -> **BMI 자동 계산**

## Screen 3. 측정 브리핑 (Test Prep)
사용자에게 어떤 테스트를 얼마나 할 것인지 마음의 준비를 시키는 화면입니다.
- **헤더:** "오늘 진행할 4가지 항목입니다. (예상 소요시간: 10분)"
- **리스트 뷰:** 
  1. 유연성 (앉아 윗몸 굽히기)
  2. 근지구력 (플랭크)
  3. 하체 근력 (월 시트)
  4. 심폐지구력 (3분 스텝)
- **하단 고정 버튼:** `[측정 시작하기]`

## Screen 4. 종목별 측정 진행 (Test Action)
실제로 몸을 움직이며 측정하는 가장 핵심적인 액티브 UI입니다. (4개 종목 반복)
- **상단 인디케이터:** 진행 상황 바 (Progress Bar: 1/4 -> 2/4)
- **중앙부 (가이드):** 올바른 자세를 보여주는 **짧은 반복 영상(GIF)이나 3D 애니메이션**
- **측정 컨트롤러:**
  - 큼직한 타이머 시계 (00:00) 또는 횟수 카운터
  - `[▶ 시작]`, `[■ 종료]` 버튼
- **기록 입력:** 측정 종료 시 기록된 시간/횟수를 확인하고 수정할 수 있는 입력창 제공 (예: 플랭크 1분 15초 버팀) -> `[다음 종목으로]` 버튼 클릭

## Screen 5. 최종 결과 리포트 (Result & Recommend)
측정 결과를 성취감 있게 보여주고 다음 행동을 유도하는 화면입니다.
- **헤더:** 폭죽 애니메이션과 함께 **"수고하셨습니다! 당신의 홈 체력은 O등급입니다"**
- **시각화 그래프 (방사형 오각형 그래프):** 
  - 5개 축: 유연성, 근지구력, 하체근력, 심폐지구력, 체성분(BMI)
  - 나의 현재 위치와 또래 평균을 겹쳐서 보여줌
- **약점 분석 및 솔루션:**
  - 텍스트 코멘트: "하체 근력은 매우 우수하지만, 심폐지구력이 조금 부족해요."
  - **추천 루틴 카드:** `[심폐지구력 향상 5분 홈트 시작하기]` 버튼을 통해 콘텐츠로 즉시 연결
