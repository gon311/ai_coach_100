# 회의 정리

날짜 : 2026년 9월 9일 

> 다음 회의는 2026-09-09에 진행된 제품 개발 점검으로, 팀은 AI 코치 기능 검증, UI/UX(웹/반응형) 구현 상태, 레이더 차트·등급 로직 및 정성·정량 평가 기준 수립을 중심으로 논의했습니다. 주요 결정사항과 담당자별 액션 아이템을 정리했습니다.

## 주요 논의 사항

- AI 코치 성능 및 동작 범위
    - 이전 기록(로그인·저장 정보)을 참조해 답변 가능. 답변 흐름은 어느 정도 만족하지만 더 많은 테스트 필요.
    - 등급에 맞는 운동 연동(4주차 등)이 보이며, 현재 데이터로도 괜찮은 응답이 나오고 있음. 다만 추가 검증 필요.
- 등급 로직(100분위 vs 등급)
    - 지난주 합의: 100분위(백분위)로 추정(100분위 기반)
    - 문제 제기: 홈(자가) 측정 시 일부 항목(악력, 심폐지구력 등)이 측정 불가 → 레이더(오각형/사각형) 시 오독 가능성
    - 결정 : 자가 측정 시 측정 가능한 항목만 표현.
    3M(노인 대상) 항목은 현재 '등급'으로 처리되어 있으나 100분위로 변경 가능 — 민님이 수정 가능하다고 확인, 3M도 100분위로 변경 결정.
- 레이더 차트(육각형/오각형/사각형) 및 대체 표시 방식
    - 수경: 자가측정 시 악력·심폐 제외한 4개 항목만 점 표시(선 연결은 일부만).
    - 다겸: 오각형/사각형 구현이 복잡하다면 단순 수치/구간 텍스트(예: 유연성 38~42)로 대체 제안.
    - 결정: 구현 난이도 고려하여 UI/UX 현실적인 범위로 진행(돌아가기엔 늦었다)
- 운동 추천 방식(개별 항목별 vs 종합 처방)
    - 수경: 현재는 “나에게 맞는 하루 운동 프로그램(종합)” 추천으로 구현됨.
    - 민: 개별 항목별 추천(유연성, 순발력 등)도 가능.
    - 결정: 하이브리드로 진행 — 종합 프로그램과 항목별 추천 둘 다 제공(프론트엔드·백엔드 연동 필요).
- UI/UX(웹/반응형/앱 형태)
    - 초기 개발은 앱처럼 보이는 웹뷰(픽셀 고정) 방식으로 작업했음.
    - 앱 빌드는 iOS 로컬서버 제약 등으로 진행하지 않기로 함. 반응형 웹으로 통일 권장(모바일 호환성 고려).
    - 결정: 반응형으로 전환, 화면 비율(사이드바 비율 등)을 비율로 잡아 유연하게 처리. 수경님이 반응형으로 변경 작업 진행.
- 리포트·측정 결과 화면 구성
    - 현재 LLM 기반 요약 문장(한 줄 설명), 레이더 차트(6개 항목), 각 항목별 추천(준비운동·본운동·마무리운동) 출력 구현 중.
    - 동영상(공단 운동 영상) 연동은 아직 백엔드 미완료 — 한호님/민님 확인 필요. 문진 결과에 따라 불가능 운동 제외 후 가능한 운동만 연동하는 로직 확인 약속.
- 센터 리스트(체력인증센터) 연동 이슈
    - 다겸: 공식 사이트(예: https://nfa.kspo.or.kr/intro/centerList.kspo)에서 센터 리스트는 보이나 CSV/JSON 형태 공개 데이터는 찾기 어려움.
    - 민: API 미구현 상태, 대안으로 사용자가 위도·경도 입력 시 근처 리스트 표시 방식 제안.
    - 액션: 팀이 센터 리스트(API/CSV/JSON 가능 여부 조사(공식 사이트 포함)) — 모두가 조사 후 노션에 업로드.
- 정성·정량 평가(성능 평가) 기준
    - 필요성: 챗봇/AI 코치 성능 신뢰도(수치화)가 사업·보고서에 필요.
    - 방안 논의:
        - 골든 라벨링을 사람이 직접 수행하면 시간이 많이 듦.
        - LLM-to-judge 같은 자동화된 저지 툴 활용 가능성 제기(다겸 제안)
        - 멘토 의견: 정성적 평가를 우선적으로 확보하는 것이 중요(정량적 수치가 뒤따름).
    - 결정/액션: 각자 정성평가 기준 및 정량 지표(참고 사례 포함)를 조사하여 노션에 업로드(토요일 1차 기한).

## 결정된 항목(요약)

- AI 코치: 추가 테스트 필요(테스트 결과에 따라 개선). 이전 기록 참조 기능은 동작함.
- 등급 로직: 3M 포함하여 기본 등급표는 100분위(백분위)로 통일(민님 수정).
- 레이더 차트/표시: 구현 난이도에 따라 육/오/사각형 유지
- 운동 추천: 하이브리드(종합 프로그램 + 항목별 추천)로 제공.
- UI 전략: 앱으로 배포하지 않음. 반응형 웹으로 통일(수경님이 반응형으로 변경).
- 동영상·운동 연동: 백엔드 연동 필요(구현 상태 확인 및 검증 필요).
- 센터 리스트: API/CSV/JSON 여부 조사(팀 전원 조사 후 노션 공유).
- 정성·정량 평가: 정성평가 우선, 정량평가 지표 및 자동 저지 도구 검토(토요일 1차 조사 마감).
