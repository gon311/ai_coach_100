## 1. 2차 회의 후 공통 확정 (기획 변경점)

### ① 측정 리포트: '종합 점수 및 인증 등급' ➡️ '백분위 및 오차 구간' 표기

- **이유:** 자가측정 데이터로는 국민체력100의 공식 인증 등급(1~6등급)을 부여할 수 없으며, 종합 점수화도 통계적 오류를 낳을 수 있습니다. (데이터 분석 파트 기준 수용)
- **변경:** 화면에 '등급'이나 '총점'은 일절 표시하지 않습니다. 대신 **"또래 상위 32%" 같은 백분위**를 기본으로 하되, 홈 자가측정의 오차를 감안해 **"상위 27~37% (자가측정 기준)" 형태의 구간**으로 표기합니다.
    - 김민
        
        각 측정항목당 백분위를 도출할수 있으니 우리는 
        
        1 / 2 / 3 / 4  / 5등급 또는 
        
        최상위 / 상위 / 중위 / 하위 / 최하위
        
        와 같은 우리의 별도 등급을 사용하는것을 추천합니다. 
        
        : **지난주 투표 결과 등급을 제외하고 백분위만 보여주는 것으로 결정되었습습니다.** 
        

### ② 사전 안전문진(PAR-Q) 게이트 엄격 적용

- 안전과 직결되므로 PAR-Q 7문항 중 하나라도 '예'가 나오면, 홈 자가측정 및 자동 처방 진행을 즉시 **차단**하고 오프라인 체력인증센터 무료 측정을 적극 유도하는 흐름으로 통일합니다. (장애유형별 분기 처리는 MVP 스펙에서 제외)

## 🚨 2. 검토 필요 사항

### AI 코치 기능: '자유 대화형 챗봇' ➡️ '정형화된 리포트 + 짧은 코멘트'

- **이유:** Qwen3 모델 테스트 결과, 긴 컨텍스트 유지와 할루시네이션(거짓 정보) 제어에 한계가 있음이 확인되었습니다. (민님이 올리신 내용 확인)
- **검토 필요 내용:** Python이 계산한 정확한 JSON 데이터를 바탕으로, **LLM은 5문장 이내의 짧은 '코치 요약 코멘트'만 생성**하여 플랜 카드와 함께 보여주는 방식을 채택할 경우 우리 서비스가 비지니스적인 면에서 매력이 있을것인가. AI코치라는 네이밍을 만족시킨다고 이야기할 수 있는지 검토가 필요합니다.
    - 김민
        
        측정결과는 파이썬으로 즉시 계산후 동영상 연결까지는 가능하지만 
        
        성능이 비교적 낮은 LLM에게 강한 하네스를 주입하니 원하는 결과는 나오지 않고 있습니다
        
        현재는 운동과 관련된 내용이면 짧게 답변 할수 있도록 하고 운동과 관련 없는 내용은 
        
        답변을 하지 않는 방향으로 계속 하네스 수정중입니다

## 🎯 3. 파트별 요청 사항 (Action Items)

### 💻 프론트엔드 (Frontend) 파트

- 현재 리포트 화면 디자인에서 측정 결과에 대한 백분위 표시가 오각형으로 되어있는데, 점추정이 아니라 구간 추정이라 이건 어떻게 표시되는지 설명 부탁드립니다.
- 김수경
    
    frontend-디자인 변경부분에선 점추정으로 표현됩니다.
    
    운동별 기준 점수도 개별로 설정하여 진행하고 있습니다.
    
    <aside>
    
    ### 성인
    
    유연성	앉아윗몸앞으로굽히기	-30 ~ +40 cm
    
    순발력	제자리멀리뛰기	0 ~ 300 cm
    
    근지구력	교차윗몸일으키기	0 ~ 100회
    
    민첩성	센터 측정 등 해당 값	0 ~ 40초
    
    악력	상대악력	0 ~ 100%
    
    심폐지구력	해당 측정값	0 ~ 150
    
    ### 만65세이상
    
    유연성	앉아윗몸앞으로굽히기	-30 ~ +40 cm
    
    순발력	측정값이 있을 경우	0 ~ 300 cm
    
    근지구력	의자에 앉았다 일어서기	0 ~ 60회
    
    민첩성	의자에 앉아 3m 표적 돌아오기	0 ~ 20초
    
    악력	상대악력	0 ~ 100%
    
    심폐지구력	2분 제자리걷기	0 ~ 150회
    
    </aside>
    
- 검토 필요 사항 논의 결과에 따라 말풍선이 오가는 챗봇 UI를 걷어내고, LLM이 넘겨주는 **'짧은 코멘트 텍스트 + 추천 운동 플랜 카드'** 가 배치되는 깔끔한 대시보드 형태로 변경 필요할 수 있습니다.

### 📊 AI/데이터 (Data) 파트

- 처방 로직 계산이 Python으로 확정될 경우, RAG가 단순 영상 메타데이터 검색용으로 쓰이는 것인지 등 그 역할을 3차 회의에서 논의해주시면 좋겠습니다.
- 아직 미정 상태인 `의자에앉아 3m 표적돌아오기` 종목의 구간 확장 폭을 확정하거나, MVP에서는 단순 '참고값' 배지로 처리할지 결정 부탁드립니다.
    - 김민(RAG)

        - 이전 대화에 나온 운동명을 참고한 후속 질문 처리
