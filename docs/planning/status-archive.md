홈 측정 배터리·리포트 설계·DB 스키마 초안까지 확정. 다년도(2022~2026) 데이터 EDA로 표본·계절성 검증 완료. 등급 표시 여부, 3m표적돌아오기 편향 판단, 청소년기 이하 연령 지원 범위는 아직 미결.

## 1. 확정된 결정 사항

### 홈 측정 종목
- 성인 배터리(4종): BMI(체중·신장), 교차윗몸일으키기, 앉아윗몸앞으로굽히기, 제자리멀리뛰기
- 어르신 배터리(5종): BMI, 의자에앉았다일어서기, 앉아윗몸앞으로굽히기, 2분제자리걷기, 3m표적돌아오기
- 허리둘레: 홈 재현 가능하나(○) **배터리에서 제외** — 코칭 로직과 무관하고, 실측 데이터상 채움률도 불안정(2022년 59.4%→2026년 43.7%, 지속 하락)
- 악력(상대/절대): **선택 모듈** — 가정용 악력계 보유 시에만 활성화
- 팀원 원안 「5대 체력 평가 운동 지표」 중 앉아윗몸앞으로굽히기·30초의자앉아일어서기 2종만 센터 정식종목과 일치해 채택, 벽스쿼트·팔굽혀펴기는 진행도 지표로 재배치, 3분스텝테스트·눈감고한발서기는 안전상 완전 제외

### 리포트 산출
- **인증등급(1~6등급) 미제공** 원칙 (단, 팀 최종 미확정 — 미결 사항 참고)
- 종목별 백분위 제공 (예: "상위 32%")
- 공단 공개 인증기준 컷오프표(한국스포츠과학원 2020 검증) 확보 완료 — 등급 판정 근거로 사용 가능
- 홈 측정 백분위는 **점추정 대신 구간**으로 표시 (예: "상위 25~40%(자가측정 기준)")
- 구간 폭 초기안(가정치, 실측 아님): 유연성 ±10%p / 교차윗몸일으키기·2분제자리걷기 ±7%p / 제자리멀리뛰기·의자에앉았다일어서기 ±5%p / 3m표적돌아오기 **미정** / BMI 점추정
- 미커버 요인(악력·심폐지구력)은 "측정 불가 — 센터 방문 권장"으로 명시, 추정치로 채우지 않음

### 장애유형별 처방
- **MVP 범위에서 제외.** 통계적 근거는 있음(일반 vs 장애유형 처방 패턴 χ²=87.9, p≈3.7×10⁻¹⁰)이나 데이터 정규화 수준이 자동 처방에 부족
- 대신 PAR-Q 안전 라우팅이 이 케이스를 흡수 (문항 5·7번이 관절·질환 관련 문제를 포괄)

### 안전 (PAR-Q)
- 공단 공식 7문항 원문 그대로 사용, **측정 이전 단계**에 게이트로 배치
- 1개 이상 '예' → 자가측정·자동처방 차단, 센터 결과 입력/영상 열람은 허용
- 문항별 응답 저장 안 함, 판정 결과(pass/fail)만 `user_screening` 테이블에 저장

### DB / 백엔드
- 단일 `measurement` 테이블 + `source` 컬럼(CENTER/HOME) — 트랙별 테이블 분리 안 함
- 추천/처방 쿼리도 단일 유지 (요인 기반 매칭)
- 홈 백분위 = 센터 기준 분포(`fitness_norm`) 그대로 적용. 홈 전용 더미 분포는 만들지 않음
- 향후 확장 방향은 "홈 전용 새 분포"가 아니라 "센터·홈 페어 표본 기반 보정계수"
- 악력은 원값(절대악력, kg)·환산값(상대악력, %) **별도 행**으로 저장 (어르신 4~6등급 판정에 절대악력 필요)
- BMI·허리둘레·혈압은 `percentile_eligible` 항상 FALSE

### 데이터 검증 (2022~2026 종합데이터 EDA로 확정)
- 성인·어르신 전 연령대×성별 서브그룹 표본 **전부 100건 이상** (최소 797건) — 5세 단위 age_band 그대로 사용
- 계절 편향 확인: 4~6월에 연간 측정의 48.7% 집중 (카이제곱 491,640) → 규준은 반드시 다년도 풀링
- 어르신 절대악력 필드: 2022년 없음 → 2023년 62.2% → 2024년 이후 98%+ → **규준은 2024년 이후 데이터만 사용**
- 인증등급 4~6단계는 **2025년부터** 실제 데이터에 등장 (그 전엔 1~3등급+참가만 존재)
- 유아기 개별 측정기록은 2023년부터 존재 (집계 데이터셋의 "2025년 10월 확대개편"과는 별개 시점)
- 원본 CSV 중 `020206.csv`(2025.06 중복), `202603.csv`(부분월, 하루치만 존재)는 분석에서 제외 처리함
