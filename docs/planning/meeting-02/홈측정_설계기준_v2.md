# 홈 측정 설계 기준 v2 — 평가 축 확정 및 종목 선정

> 작성: 데이터 분석 파트
> 대상: 「5대 체력 평가 운동 지표」 문서에 대한 검토 및 대체안
> 결론 요약: **원본 6개 항목 중 2개(앉아윗몸앞으로굽히기, 30초 의자 앉아 일어서기)는 센터 종목과 일치하므로 프로토콜 그대로 채택하고 기준표만 공단 백분위로 교체. 나머지 4개는 진행도 지표 이관 또는 안전상 제외. 자료근거의 국민체력100 오귀속은 즉시 정정 필요.**
>
> 추가 확정 사항: 인증등급 미제공(4절) / 장애유형별 처방 MVP 제외 + PAR-Q 통합 안전 라우팅(5절) / 추천 쿼리 단일 유지(6절) / 공단 PAR-Q 7문항을 측정 전 게이트로 채택(9절)

## v2 변경 이력

문화빅데이터플랫폼 「체력측정 및 운동처방 종합 데이터」 2022.01~2026.07 (55개월, 143만 행, 고유회원 93.9만 명)을 전수 분석해 8절을 신규 추가했다. 기존 결정(1~7, 9절)을 뒤집는 내용은 없으며, 아래 두 가지가 핵심이다.

- **서브그룹 표본 규모 검증 완료** — 성인·어르신 전 연령대×성별 셀이 MIN_SAMPLE=100을 전부 충족 (최소 797건). 5세 단위 `age_band` 그대로 확정.
- **계절 편향 정량 확인** — 4~6월에 연간 측정의 48.7%가 집중(카이제곱=491,640, df=11). 규준은 반드시 다년도 풀링으로 구축하고, 단일·소수 월 데이터를 규준으로 쓰지 않는다는 원칙을 재확인.

상세는 8절 참조.

**추가 개정 (구간 표기 관련)**

- **4-6절 신설** — 자가측정 편향 방향·크기 판단표. 홈 배터리가 센터 정식 종목·동일 프로토콜로 구성되어 척도 불일치가 없다는 점을 명시하고, 남는 문제인 측정 조건 편향을 종목별로 정리했다. 구간 폭 초기안의 근거 문서가 된다.
- **4-3절·6-4절 예시 수치 정정** — 문서 내 구간 예시가 종목별 초기안과 어긋나 있었다(32~45%, 25~40% 등). 종목별 폭에 맞춰 통일했다.

## 1. 센터 측정 종목 전체 (평가 축의 정본)

### 성인기 (만 19~64세)

| 구분 | 요인 | 측정 항목 |
|---|---|---|
| 체격 | 신체조성 | 신장, 체중, BMI, 체지방률, 허리둘레 |
| 체격 | 안전 스크리닝 | 이완기혈압, 수축기혈압 |
| 건강체력 | 근력 | 상대악력 |
| | 근지구력 | 교차윗몸일으키기 |
| | 심폐지구력 | 20m 왕복오래달리기 / 스텝검사 / 트레드밀 (택1) |
| | 유연성 | 앉아윗몸앞으로굽히기 |
| 운동체력 | 민첩성 | 10m 왕복달리기 / 반응시간검사 (택1) |
| | 순발력 | 제자리멀리뛰기 / 성인체공시간 (택1) |

**택1 항목 실사용 비율** (문화빅데이터 종합데이터 2025.06~07 실측, n=70,200):
- 심폐지구력: 스텝검사 65.8% · 왕복오래달리기 21.2% · 트레드밀 12.9% (트레드밀은 9분 단계만 2.2%로 급감 — 해당 구간은 규준 표본 부족 가능성 높음)
- 민첩성: 반응시간 68.9% · 10m왕복달리기 23.9%
- 순발력: 제자리멀리뛰기 56.4% · 성인체공시간 36.6%
- 허리둘레는 47.1%만 채워짐 — 2025년 10월 개편 전후로 수집 여부가 갈렸을 가능성

### 어르신기 (만 65세 이상)

| 요인 | 측정 항목 |
|---|---|
| 신체조성 | 신장, 체중, BMI, 체지방률, 허리둘레 |
| 안전 스크리닝 | 이완기혈압, 수축기혈압 |
| 상지 근기능 | 상대악력, **절대악력(kg)** |
| 하지 근기능 | 의자에앉았다일어서기(30초) |
| 유연성 | 앉아윗몸앞으로굽히기 |
| 심폐지구력 | 2분제자리걷기 / 6분걷기 (택1) |
| 협응력 | 8자보행 |
| 민첩·동적평형성 | 의자에앉아 3m 표적돌아오기 |

**절대악력 추가 근거**: 공식 인증기준표의 어르신 4~6등급 판정은 상대악력(%)이 아니라 **절대악력(kg)**을 기준으로 한다. 상대악력만 저장하면 해당 등급 구간을 산정할 수 없다.

**택1 항목 실사용 비율**: 2분제자리걷기 83.5% vs 6분걷기 1.6% — 6분걷기는 사실상 쓰이지 않는다. 홈 배터리에서 2분제자리걷기만 채택한 기존 결정(3절)과 일치한다.

**안전 스크리닝 항목 처리 주의**: 혈압은 성별·연령별 규준을 매겨 "우수/부족"을 논하는 체력 지표가 아니라, 측정 가능 여부를 가리는 **문진 성격의 값**이다. BMI·허리둘레와 마찬가지로 백분위 파이프라인에 넣지 않고 정상/주의 범위의 카테고리 판정으로만 다룬다.

**주의**: 연령군마다 요인 세트가 다르다. 5개 고정 스키마로는 어르신기의 협응력·동적평형성을 담을 수 없다. 스키마는 연령군별 종목 세트를 수용하는 구조여야 한다.

## 3. 권장 홈 측정 배터리 v1

위 매트릭스에서 **○ 등급만 채택**한 최소 구성. 이것만으로 요인 커버리지가 상당 부분 확보된다.

**원본 문서 재사용**: 아래 종목 중 `앉아윗몸앞으로굽히기`와 `의자에앉았다일어서기`는 「5대 체력 평가 운동 지표」에 이미 정확한 프로토콜이 작성되어 있다. 해당 기술을 그대로 가져오고 **기준표만 공단 백분위로 교체**한다.

**성인기 (4종)**
1. 신장·체중 → BMI (신체조성)
2. 교차윗몸일으키기 (근지구력)
3. 앉아윗몸앞으로굽히기 (유연성)
4. 제자리멀리뛰기 (순발력)

→ 미커버: 근력(악력), 심폐지구력. 리포트에서 **"측정 불가 — 센터 방문 권장"**으로 명시적 표기. 빈칸을 추정치로 채우지 않는 것이 오히려 신뢰도 어필 포인트가 된다.

**어르신기 (5종)**
1. 신장·체중 → BMI
2. 의자에앉았다일어서기 (하지 근기능)
3. 앉아윗몸앞으로굽히기 (유연성)
4. 2분제자리걷기 (심폐지구력)
5. 의자에앉아 3m 표적돌아오기 (민첩·동적평형성)

→ 미커버: 상지 근기능(악력), 협응력(8자보행)

**허리둘레 미채택 사유**: 판정은 ○(줄자만 있으면 재현 가능)이지만 배터리에는 넣지 않는다. 백분위·레이더 차트·운동처방 매핑 어디에도 걸리지 않는 신체조성 스크리닝 값이라, 넣어도 코칭 로직에는 영향이 없고 리포트 UI에 체형 정보 카드 하나가 늘어날 뿐이다. 2절 매트릭스에는 판정 기록만 남겨두고(추후 확장 시 참고), 이번 배터리에서는 제외한다.

### 3-1. 악력 선택 모듈

미커버 요인 중 **악력만은 해결 가능**하다. 심폐지구력은 20m 직선 공간·음원·안전 게이트가 모두 필요하지만, 악력은 **디지털 악력계 하나**로 프로토콜이 완전히 재현된다. 체중은 이미 배터리에 포함되어 있으므로 `상대악력 = 악력(kg) / 체중(kg) × 100` 환산도 즉시 가능하다.

| 사용자 상태 | 처리 |
|---|---|
| 악력계 보유 | 근력 항목 활성화, `equipment_verified = TRUE`, **정식 백분위 산출** |
| 미보유 | 항목 비활성 + "악력계가 있으면 근력도 측정할 수 있어요" 안내 |

기존 스키마의 `equipment_verified` 컬럼으로 그대로 처리되며 구조 변경이 필요 없다.

### 3-2. 대체 종목으로 요인을 채우지 않는 이유

"악력 대신 팔굽혀펴기로 근력을 재자"는 방향은 채택하지 않는다.

- **백분위는 종목에 종속된다.** "상위 30%"는 *상대악력 분포* 위에서만 정의된다. 공단이 측정한 적 없는 종목에는 대응 분포가 존재하지 않으므로 백분위를 산출할 경로가 없다.
- **정식 방법은 동등화(equipercentile equating)** 이며, 두 검사를 모두 받은 가교 표본이 성별·연령대별로 수백 명 단위 필요하다. 공모전 기간 내 불가능하다.
- **회귀 예측은 실패한다.** 다른 측정값으로 악력을 추정하면 평균 회귀로 예측값이 압축되어 **거의 모든 사용자가 "보통"으로 나오는** 리포트가 만들어진다.
- **맨몸 종목은 애초에 근력이 아니다.** 팔굽혀펴기·플랭크·벽스쿼트는 반복 횟수/유지 시간을 측정하므로 실질적으로 **근지구력** 검사다. 최대근력은 외부 부하나 계측 기기 없이 원리적으로 측정할 수 없다. 대체 종목을 넣어도 근력 칸이 채워지는 것이 아니라 이미 커버된 근지구력이 중복될 뿐이다.

**중요**: ○ 항목이라도 자가측정에는 감독자 부재로 인한 오차가 남는다. 백분위를 점 추정치로 단정하지 말고 **구간(예: 상위 30~45%)으로 표기**하는 것을 권장한다. 이 역시 방법론적 성실성으로 평가받을 수 있는 지점이다.

## 4. 리포트 산출 범위 — 무엇을 주고 무엇을 주지 않는가

홈 측정은 센터 대비 항목이 누락되므로, **리포트(비교·평가)는 보수적으로 제한하고 처방(영상·루틴)은 정상 작동**시키는 것이 본 서비스의 실제 구조다. 이 두 축의 요구 조건이 서로 다르다는 점이 설계의 핵심이다.

### 4-1. 인증등급은 제공하지 않는다

**구조적 이유**
인증등급은 종목별 등급의 단순 평균이 아니라 조합 규칙으로 산출된다. 성인기는 운동체력에서 민첩성·순발력 중 높은 등급을 택하고, 어르신기는 "8자보행과 상지근기능(절대악력) 또는 8자보행과 하지근기능이 3등급 인증기준 이상" 형태의 AND/OR 조건이 걸린다. 근력·심폐 항목이 비면 이 규칙 자체를 실행할 수 없다.

**제도적 이유 (더 중요)**
국민체력100 등급은 공단이 인증센터를 통해 발급하는 **국가 인증**이며, 군 간부 모집·일부 지자체 채용 등에서 실제 효력을 갖는다. 자가측정 결과로 "2등급입니다"를 표시하면 공적 인증을 사칭하는 형태가 된다. 심사 주체가 공단인 점을 고려하면 이는 회피 대상이 아니라 절대 금지선이다.

### 4-2. 대신 제공하는 것

| 제공 항목 | 내용 | 근거 |
|---|---|---|
| **종목별 백분위** | "제자리멀리뛰기 상위 32%" | 측정 종목의 공단 분포에서 직접 산출 |
| **공개 기준선 대비 충족 여부** | "이 종목 기록은 성인 남성 3등급 기준선 이상" | 공단이 공개한 등급 컷오프와의 사실 비교. 등급을 *발급*하지 않고 *기준선과 대조*만 함 |
| **미측정 항목 명시** | "근력·심폐지구력 — 자가측정 불가" | 추정치로 채우지 않음 |
| **센터 방문 안내** | "정식 인증등급은 체력인증센터에서 무료로 받을 수 있습니다" + 센터 위치 | 기획서 확장 기능과 연결 |

마지막 항목은 방어 논리가 아니라 **강점**으로 포지셔닝한다. 공공 인프라로 사용자를 유입시키는 구조이므로 공공서비스 취지에 부합한다.

### 4-3. UI 표기 문구 (초안)

- 종목별: `제자리멀리뛰기 172cm — 또래 상위 27~37% (자가측정 기준)` ← 점추정 32%에 ±5%p 적용
- 종목별(폭이 넓은 경우): `앉아윗몸앞으로굽히기 8.5cm — 또래 상위 22~42% (자가측정 기준)` ← 점추정 32%에 ±10%p 적용
- 미측정: `근력 — 측정하지 않음. 악력계가 있으면 측정할 수 있어요` / `심폐지구력 — 자가측정 불가. 가까운 체력인증센터에서 무료 측정 가능`
- 하단 고정: `본 리포트는 자가측정 기반 참고 정보이며, 국민체력100 공식 인증등급이 아닙니다. 의학적 진단을 대체하지 않습니다.`

### 4-4. 운동 영상 연결은 정상 작동한다

등급과 달리 처방 파이프라인은 항목 누락의 영향을 거의 받지 않는다.

- **처방 데이터가 등급에 종속되지 않음** — 확보한 처방결과 CSV에서 `grade` 컬럼이 전체 null이었다. 매칭이 등급 키로 이루어지지 않는다는 근거이며, 요인·연령·성별(·장애유형) 조합으로 동작하면 등급 없이 그대로 작동한다.
- **추천은 순위 문제** — "당신의 약점은 유연성"을 말하는 데 필요한 것은 측정한 항목들 간의 상대 순위이지 전체 등급이 아니다. 4종만으로도 그 안의 최약점은 도출된다.
- **콘텐츠가 공단 공식 자산** — 통계를 새로 생성하는 것이 아니라 공단이 제작한 요인별 처방 콘텐츠를 연결하는 것이므로 근거 부담이 근본적으로 낮다.

### 4-5. 다만 반드시 처리해야 할 편향

측정하지 않은 요인은 **영원히 처방되지 않는** 구조적 편향이 발생한다. 실제 약점이 심폐인 사용자가 심폐 운동을 한 번도 추천받지 못하는 상황이며, 홈트 사용자에게 유산소를 권하지 않는 것은 명백한 서비스 결함이다.

**대응 2층 구조**

1. **기본 루틴에 유산소·근력을 무조건 포함.** 신체활동 지침상 모든 성인에게 필요한 요소이므로 측정 여부와 무관하게 포함한다. 처방 로직을 "약점 보완"만으로 짜지 말고 **"기본 구성 + 약점 가중"** 으로 설계한다.
2. **미측정 요인은 자가보고 문진으로 보완.** 주당 유산소 시간, 근력운동 빈도 등. 단 이는 측정이 아니므로 **백분위 파이프라인에는 절대 투입하지 않고** 처방 가중치에만 반영하며, UI에도 "자가응답 기반"으로 구분 표기한다.

### 4-6. 자가측정 편향 방향·크기 판단표

홈 배터리는 센터 정식 종목·동일 프로토콜로만 구성했으므로 **척도 불일치 문제는 없다.** 값의 단위와 의미가 같으므로 센터 분포(`fitness_norm`)를 그대로 적용해 백분위를 산출할 수 있고, 홈 전용 분포를 만들 필요가 없다.

**남는 문제는 척도가 아니라 측정 조건이다.** 센터는 규격 장비와 측정자 통제가 있고 가정에는 없다. 아래 표는 그 차이가 어느 종목에서 얼마나 크게 나타날지에 대한 판단이며, **구간 폭 초기안의 유일한 근거**다.

| 종목 | 주요 편향 요인 | 방향 | 크기 | 구간 폭 초기안 |
|---|---|---|---|---|
| 앉아윗몸앞으로굽히기 | 센터 좌전굴 측정기는 발바닥 접촉면이 0점으로 고정. 가정에서는 상자·계단 높이와 영점 정의가 임의 | 양방향 **(계통 오차)** | **큼** — 수 cm 단위로 값 전체가 이동 가능 | ±10%p |
| 교차윗몸일으키기 | 무릎 각도·어깨 바닥 접촉·팔 위치가 미검증. 다만 측정음원이 공단 공식 배포라 템포는 통제됨 | 상향 | 중 | ±7%p |
| 2분제자리걷기 | 무릎 높이 표식(슬개골 상단~장골능 중간) 설정과 도달 판정이 자가측정에서 느슨해짐 | 상향 | 중 | ±7%p |
| 제자리멀리뛰기 | 발끝 선 기준·착지 시 뒤쪽 접지점 판정 해석 차이 | 상향 | 소 | ±5%p |
| 의자에앉았다일어서기 | 의자 좌면 높이(약 43cm) 편차. 낮으면 유리, 높으면 불리 | 양방향 | 소~중 | ±5%p |
| 의자에앉아 3m 표적돌아오기 | 콘 배치 거리, 자가 계시(스톱워치 조작 지연) | **미정** | **미정** | **미정** |
| 신장·체중 → BMI | 가정용 체중계 오차만 | — | 무시 가능 | **해당 없음** (백분위 비대상 / 값은 점추정) |

**표 읽는 법과 주의사항**

- **이 표는 실측이 아니라 판단이다.** 센터·홈 페어 표본(동일인이 두 방식으로 측정한 데이터)이 없으므로 실제 편향 크기는 알 수 없다. 프로토콜상 통제되지 않는 변수의 **개수와 민감도**를 근거로 상대 순위를 매긴 것이다. 리포트·보고서에는 반드시 "가정 기반 초기값이며 데이터 축적 후 보정"으로 명시한다.
- **방향이 '상향'인 종목의 구간은 원칙적으로 비대칭이어야 한다.** 폼이 느슨해지면 기록이 실제보다 좋게 나오므로 하향 보정이 더 필요하다. 다만 비대칭 폭을 정할 근거 역시 없으므로 **초기안은 대칭 ±로 둔다.** 이 단순화 자체를 문서에 남긴다.
- **BMI는 구간 폭 논의 대상이 아니다.** 여기서 두 가지를 구분해야 한다. **BMI 값 자체**(예: 22.4)는 신장·체중으로 계산되는 단일 확정값이고 가정용 체중계 오차가 무시할 수준이므로 **점추정으로 표시하는 것이 맞다.** 반면 **BMI 백분위**는 존재하지 않는다 — `percentile_eligible = FALSE` 고정 항목이라 애초에 산출하지 않기 때문이다(7절, 정규화 스펙 2-2절). 위 표의 다른 행은 전부 "백분위를 몇 %p 폭으로 넓힐까"에 대한 값이므로, BMI는 같은 축에 놓이지 않는다. 값은 점추정, 해석은 구간 판정(저체중/정상/과체중/비만). 허리둘레·혈압도 동일하게 처리한다.
- **3m표적돌아오기는 미결이다.** 어르신 배터리 5종에 포함되어 있으나 편향 방향·크기 모두 판단되지 않았다. 자가 계시 오차는 상향(기록 단축)으로 작용할 가능성이 높지만, 콘 배치 거리 오차는 양방향이다. 확정 전까지 이 종목은 **구간 표시 대신 "참고값" 배지로 처리**하는 것을 권장한다.

**편향을 줄이는 쪽이 구간을 좁히는 쪽보다 우선한다.** 특히 유연성 영점 정의와 의자 높이는 측정 가이드에서 그림으로 규격을 고정하면 편향 자체가 줄어든다. 구간 폭은 남은 오차를 표기에 반영하는 수단이지, 가이드 부실을 덮는 수단이 아니다.

## 5. MVP 제외 범위와 근거 — 장애유형별 처방

### 5-1. 결정

장애유형별 운동처방은 **MVP 범위에서 제외**한다. 사전 EDA에서 해당 데이터의 정규화 수준이 자동 처방에 요구되는 신뢰도에 미치지 못함을 확인했다.

### 5-2. 근거 (보고서 인용용)

> 장애유형별 처방 데이터를 분석한 결과 일반 처방과 패턴이 통계적으로 유의하게 상이함을 확인했다(χ²=87.9, p≈3.7×10⁻¹⁰). 일반 그룹에서 높은 비중을 차지하는 달리기 계열 운동이 장애유형 그룹에서는 0%였으며, 균형·저부하 협응 운동이 주를 이루었다. 그러나 해당 데이터의 정규화 수준이 자동 처방에 필요한 신뢰도에 미치지 못해, MVP 범위에서 제외하고 **전문가 상담 경로로 라우팅**하기로 결정했다.

이는 "구현하지 않음"이 아니라 **"검증한 뒤 근거를 갖고 스코프에서 제외함"** 이다. 보고서의 한계·향후과제 절에 그대로 사용한다.

### 5-3. 제외의 범위 — 반드시 구분할 것

제외에는 두 종류가 있으며, **전자만** 해당한다.

| 구분 | 채택 여부 |
|---|---|
| 장애유형별 **처방 분기**를 만들지 않음 | ○ 채택 |
| 장애가 있는 사용자의 **서비스 이용을 차단** | ✕ 하지 않음 |

**주의**: 아무 분기도 두지 않으면 자동으로 세 번째 상태가 된다 — *장애가 있는 사용자가 일반 처방을 그대로 받는 것*. 5-2절의 통계적 근거를 보유한 상태에서 일반 처방을 내보내는 것은 근거가 없는 상태보다 나쁘다.

### 5-4. 필수 구현: 안전 라우팅 (PAR-Q로 통합)

장애·질환 관련 트리거를 **별도로 설계하지 않는다.** 공단이 측정 1단계로 제공하는 사전신체상태설문지(PAR-Q) 7문항이 이 기능을 흡수한다. 상세 설계는 **9절** 참조.

- 특히 5번(운동 시 악화될 수 있는 관절·뼈 문제)과 7번(신체활동을 해서는 안 되는 다른 이유)이 본 절이 대응하려던 케이스를 기능적 관점에서 포괄한다.
- 우리가 "장애 유무·유형"을 직접 질문하지 않으므로 **민감정보 수집을 회피**할 수 있고, 유형 분류 체계를 설계할 필요도 없다.
- 트리거는 `parq_passed = FALSE` 단일 조건으로 통합한다.

**게이트 위치 주의**: 이 판정은 처방 단계가 아니라 **측정 이전 단계**에 둔다. 우리 홈 배터리에도 제자리멀리뛰기·교차윗몸일으키기 등 최대 노력 과제가 포함되므로, 위험 요소는 처방된 운동만이 아니라 **측정 행위 자체**다. 공단도 이를 1단계에 배치하고 있다.

### 5-5. 기존 EDA 결론의 처리

| 분석 결과 | 상태 |
|---|---|
| 운동 어휘 완전 포함 관계 → 단일 매핑 테이블로 처리 가능 | **유효** (일반 처방만 사용하므로 오히려 단순해짐) |
| 장애유형별 처방 분기 설계 | 폐기 |
| 장애유형 그룹 주운동 null 32.2% vs 일반 17.3% | 참고자료로 보존 (제외 근거의 일부) |
| 장애유형 유무 fallback 라우팅 | **유지** — 처방 분기가 아닌 **안전 요건**으로 성격 변경 |

## 6. 추천 쿼리 설계 — 트랙별로 나누지 않는다

센터 트랙과 홈 트랙은 **입력과 리포트에서만** 갈라지며, 영상 추천 쿼리는 단일하게 유지한다.

### 6-1. 계층별 분기 여부

| 계층 | 분기 | 이유 |
|---|---|---|
| 입력 UI | **○** | 센터는 결과지 전사(7종), 홈은 측정 가이드(4~5종). 화면 구성이 다름 |
| 저장 | ✕ | 단일 `measurement` 테이블, `source` 컬럼으로 구분 |
| 백분위 산출 | ✕ | `percentile_eligible` 필터만 적용 |
| 리포트 표기 | **○** | 등급 표시 여부, 미측정 항목 문구, 신뢰구간 폭 |
| **영상 추천** | ✕ | 동일 쿼리 |

### 6-2. 단일 쿼리가 성립하는 이유

추천 로직의 입력은 "센터냐 홈이냐"가 아니라 **"약한 요인이 무엇이냐"** 다. 사용자 유형이 아니라 요인이 키다.

```sql
-- 트랙 구분 없이 동작
SELECT m.factor_code, m.percentile
FROM measurement m
WHERE m.user_id = ?
  AND m.percentile_eligible = TRUE
ORDER BY m.percentile ASC
LIMIT 3;
```

센터 사용자는 7행, 홈 사용자는 4행이 반환될 뿐 쿼리는 동일하다. `percentile_eligible`을 컬럼으로 미리 계산해두었으므로 하위 로직 전체가 트랙을 알 필요가 없다.

**쿼리를 두 벌 유지하면**: 처방 규칙 변경 시 양쪽을 동일하게 수정해야 하고, 한쪽만 수정되는 순간 두 트랙이 서로 다른 운동을 추천한다. 테스트로 잡기 어려운 유형의 결함이다.

### 6-3. 실제 분기 조건은 트랙이 아니다

```
if 장애·질환 문진 해당       → 자동 처방 중단, 상담 안내 (5-4절)
if 미측정 요인 존재          → 기본 루틴 보강 (4-5절)
```

두 번째 조건은 홈 트랙과 상관관계가 있으나 **동일하지 않다.** 센터에서도 항목이 누락될 수 있고(스텝검사만 시행), 악력계 보유 홈 사용자는 근력이 채워진다. 따라서 `source = 'HOME'`이 아니라 **측정된 요인 집합**으로 판단해야 한다.

이 설계는 "센터 측정 후 홈에서 재측정"하는 사용자를 쿼리 수정 없이 수용한다. 확장 기능의 재측정 추이 트래킹과 호환된다.

### 6-4. 표기 계층의 source 분기

같은 종목이라도 센터 측정과 자가측정은 오차 구조가 다르므로, 백분위를 동일한 확신도로 표기하지 않는다.

```
CENTER → "상위 32%"
HOME   → "상위 27~37%"   -- 제자리멀리뛰기(±5%p) 기준
       → "상위 22~42%"   -- 앉아윗몸앞으로굽히기(±10%p) 기준
```

**확장 폭은 종목마다 다르다.** 일괄 값이 아니라 종목별 설정 맵으로 관리한다 (근거·수치는 4-6절).

쿼리 분기가 아니라 **리포트 조립 단계**에서 처리한다.

## 7. 데이터 스키마 반영

측정 레코드에 아래 컬럼을 추가해 신뢰도 등급이 리포트에 자동 반영되도록 한다.

```
measurement (
  measurement_id      BIGINT PK,
  user_id             BIGINT,
  age_group_code      VARCHAR(20),   -- 유아/유소년/청소년/성인/어르신
  item_code           VARCHAR(40),   -- 센터 종목 코드 (정본)
  factor_code         VARCHAR(30),   -- 신체조성/근력/근지구력/심폐지구력/유연성/민첩성/순발력/협응력
  raw_value           DECIMAL(8,2),
  unit                VARCHAR(10),
  source              ENUM('CENTER','HOME'),
  protocol_match      ENUM('EXACT','PARTIAL','NONE'),
  equipment_verified  BOOLEAN,       -- 필수 기구 보유 확인 여부
  percentile_eligible BOOLEAN,       -- source·protocol_match 조합으로 결정
  measured_at         DATETIME
)
```

- `percentile_eligible = TRUE` 조건: `protocol_match = 'EXACT'` AND `equipment_verified = TRUE`
- `FALSE`인 레코드는 백분위 산출 파이프라인에서 제외하고, UI에 "참고값" 배지 표시
- **BMI·허리둘레·혈압은 장비/프로토콜 문제와 무관하게 항상 `percentile_eligible = FALSE`로 고정한다.** 이 항목들은 측정 품질이 아니라 U자형 분포(중간이 최적) 또는 스크리닝 성격 때문에 백분위 자체가 성립하지 않는다. 별도의 구간 판정(저체중/정상/과체중/비만 등) 로직으로 처리한다.
- **악력은 한 번의 측정에서 두 개의 `item_code` 행을 만든다** — 원값(절대악력, kg)과 환산값(상대악력, %)을 별도 행으로 저장한다. 어르신 4~6등급 판정은 절대악력(kg) 기준이므로, 상대악력만 저장하면 해당 등급 구간을 계산할 수 없다.
- 운동 부위 분류(상체/하체 등)는 이 테이블이 아니라 **처방 매핑 테이블**에 태그로 둔다 (측정 축과 처방 축 분리)

- 봄철 응시자와 겨울철 응시자의 인구 구성(연령·목적—학기 초 체력장 대비 vs 개인 자발적 방문 등)이 다를 가능성이 있어, 추후 여력이 되면 월별 하위집단 특성 차이도 점검할 가치가 있다(현재는 스코프 밖).

### 8-8. 입력 경로 3종 확인 — 자가측정 데이터 없음 결론은 불변

`INPT_FLAG_NM`(입력구분) 전체 분포: 관리자 1,403,988건(97.9%) · 측정기기 24,120건(1.7%) · 인바디 5,831건(0.4%).

2개월 샘플에서는 "관리자"만 보였으나 전체 데이터엔 자동 계측 장비(측정기기)·체성분 전용기기(인바디) 연동 입력도 있었다. **다만 셋 다 센터 현장의 입력 경로**이며, 자가측정·홈 입력에 해당하는 카테고리는 4.5년 전체에서 단 한 건도 없다. 이 데이터로 "자가측정이 센터 측정 대비 얼마나 오차가 나는지"는 검증할 수 없다는 기존 결론은 그대로 유지된다 — 그 검증은 별도로 팀원 몇 명이 두 방식 모두 측정해 비교하는 절차가 필요하다.

`MESURE_PLACE_FLAG_NM`(측정장소)도 전체 기준으로는 출장(찾아가는 서비스) 59.3%, 일반(상시센터) 40.7%로 2개월 샘플보다 출장 비중이 더 높았다. 두 경로 모두 센터 소속 인력이 수행하는 측정이라 결론에 영향은 없다.

## 10. 사전 문진 (PAR-Q) 설계

### 10-1. 문항은 공단 원문을 그대로 사용한다

자체 문항을 작성하지 않는다. 문항을 직접 만들면 "출처 없는 자체 기준" 문제가 재발한다. 공단이 체력측정 **1단계**로 제공하는 사전신체상태설문지 7문항을 원문 그대로 사용한다.

| 문항 | 내용 |
|---|---|
| 1 | 의사에게 심장질환 진단을 받았거나, 신체활동/운동 삼가에 대한 말을 들은 적이 있습니까? |
| 2 | 운동을 할 때 가슴에 통증이 있습니까? |
| 3 | 지난달 휴식 시에도 가슴에 통증을 느낀 적이 있습니까? |
| 4 | 어지럼증으로 쓰러졌거나 의식을 잃은 적이 있습니까? |
| 5 | 운동할 때 심해질 수 있는 관절이나 뼈의 문제(예: 허리, 무릎 또는 고관절)가 있습니까? |
| 6 | 심장질환 등으로 의사에게 처방 받아 복용하는 약이 있습니까? |
| 7 | 신체활동/운동을 해서는 안되는 다른 이유가 있습니까? |

응답 형식: 각 문항 '예' / '아니오'

### 10-2. 판정 기준도 공단 기준을 따른다

> 1개 이상 '예'가 있을 경우, 체력측정 시 위험할 수 있으므로 전문가 상담 후 진행

**문항별 차등 판정(예: 5번만 해당하면 유연성 측정은 허용)을 설계하지 않는다.** 그것은 근거 없는 자체 기준을 다시 만드는 일이다. 공단과 동일 기준을 사용하면 심사에서도 한 줄로 설명된다.

### 10-3. 게이트 위치 — 측정 이전

```
① 문진 (PAR-Q 7문항)
      │
      ├─ 전부 '아니오' ──→ ② 자가측정 가이드 ─→ ③ 백분위 리포트 ─→ ④ 처방·루틴
      │
      └─ 1개 이상 '예' ──→ 자가측정 차단 + 센터 안내
                            (센터 결과 입력 경로는 계속 이용 가능)
```

홈 배터리에도 제자리멀리뛰기·교차윗몸일으키기 등 최대 노력 과제가 포함되므로, 게이트를 처방 단계에 두면 이미 측정을 수행한 뒤가 되어 늦다.

### 10-4. 미통과 시 기능 제어

공단은 현장에 전문가가 있어 상담 후 측정 진행이 가능하지만, 자가측정 환경에는 감독자가 없다. 따라서 한 단계 더 보수적으로 설계한다.

| 기능 | 미통과 시 |
|---|---|
| 자가측정 가이드 | **차단** |
| 자동 운동처방·주간 루틴 | **차단** |
| 센터 결과 입력 → 백분위 리포트 | **허용** (이미 전문가 감독하에 측정된 값) |
| 공단 운동 영상 열람 | 허용 (일반 콘텐츠 열람이며 개인 처방이 아님) |
| 센터 안내 | 강조 노출 |

**핵심**: 서비스에서 배제하는 것이 아니라 안전한 경로(센터 트랙)로 유도하는 구조다.

### 10-5. 민감정보 처리

건강 관련 정보는 개인정보보호법상 **민감정보**에 해당한다. 7문항 응답을 저장하면 별도 동의와 보관 근거가 필요해진다.

**권장: 응답 원문을 저장하지 않고 판정 결과만 보관**

```sql
user_screening (
  user_id      BIGINT PK,
  parq_passed  BOOLEAN,     -- 판정 결과만 저장
  screened_at  DATETIME,
  valid_until  DATE         -- 재문진 주기 (예: 6개월)
)
```

- 개별 문항 응답은 세션에서만 처리하고 폐기한다.
- 이 결과는 **백분위 산출이나 처방 가중치에 절대 투입하지 않는다.** 스크리닝 판정이지 측정값이 아니다.
- 유효기간 경과 시 재문진을 요구한다.
